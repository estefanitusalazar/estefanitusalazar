## How I document my work

For portfolio projects I try to show:

1. the problem being solved;
2. the technical approach;
3. architecture and important decisions;
4. testing or validation evidence;
5. security and privacy considerations;
6. what is implemented versus what is still experimental.

Some projects are intentionally **showcase-only**. Their public repositories do not contain the complete implementation, proprietary logic, academic deliverables or sensitive data. Full source may be reviewed privately when appropriate.
