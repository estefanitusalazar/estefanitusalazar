# MusicPro — Warehouse System Modelling

## Overview

MusicPro is a software-modelling project for a central warehouse. The objective was to translate business needs into a structured software solution before implementation.

## Work completed

The project includes:

- functional and non-functional requirements;
- actor identification and use cases;
- relational data modelling;
- process-flow diagrams;
- interface mockups;
- user stories with acceptance criteria;
- Kanban planning and work-in-progress limits.

## Data model

The warehouse model covers entities such as:

- roles and users;
- categories and products;
- brands and suppliers;
- lots;
- receptions and reception details;
- inventory-related operations and warehouse requests.

Primary and foreign keys were used to make relationships explicit and support referential integrity.

## Agile planning

Twenty user stories were documented and connected to functional requirements. Stories include priorities, proposed owners, target dates and acceptance criteria.

The Kanban workflow distinguishes between:

- backlog / task list;
- to do;
- in progress;
- review;
- done.

Work-in-progress limits were proposed to keep execution focused rather than moving every story into development at once.

## Important portfolio note

This project is presented honestly as **analysis, modelling and planning**, not as a fully implemented production backend. The value of the work is in requirements engineering, traceability, data modelling, UML/process representation and delivery planning.
