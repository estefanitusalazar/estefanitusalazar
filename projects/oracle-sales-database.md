# Oracle Sales Database — Retail Case Study

## Overview

Relational database project developed in Oracle Database / SQL Developer for a retail sales scenario.

The implementation created a dedicated `VENTAS` schema and modelled the core entities required to manage customers, products, sales and sale details.

## Core schema

- `CLIENTES`
- `PRODUCTOS`
- `VENTAS`
- `DETALLE_VENTA`

The tables were designed with primary and foreign keys to preserve relationships and referential integrity.

## SQL work demonstrated

- schema/user setup;
- table creation;
- primary and foreign keys;
- test data insertion;
- filtered and ordered queries;
- simple views;
- joined/compound views;
- sequences and `NEXTVAL`;
- indexes;
- synonyms;
- validation of relationships with test records.

## Why it is in the portfolio

The project demonstrates the ability to move from a business requirement to a working relational model and then validate it through SQL operations in Oracle.
